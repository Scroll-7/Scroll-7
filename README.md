### Fake News Detector

A multi-modal misinformation and deepfake detection platform that analyzes **text, URLs, and images** and produces a credibility score with an evidence-based verdict.

The project combines:

* Node.js and Express
* Python and FastAPI
* Groq LLaMA vision models
* Google Gemini
* scikit-learn
* ONNX Runtime
* InsightFace
* Computer vision and image analysis
* Rule-based forensic analysis
* Automated testing with Playwright
* GitHub Actions

The system combines multiple AI and local analysis services instead of relying on a single model.

[View Project](https://github.com/Scroll-7/Fake-exposer)
